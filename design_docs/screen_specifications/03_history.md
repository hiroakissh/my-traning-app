# 3. 履歴画面

## 3.1. 画面概要

過去のトレーニング記録を閲覧・分析し、自身の成長を可視化するための画面。

## 3.2. 表示項目

-   **表示モード切替:**
    -   「カレンダー」「リスト」「分析」を切り替えるタブまたはセグメンテッドコントロール。
-   **共通フィルタ:**
    -   検索バー（種目名・メモ・目的などに部分一致）。
    -   カテゴリフィルタ（`ExerciseCategory`）を選択するメニュー。未選択は「すべて」。
-   **カレンダー表示モード:**
    -   トレーニングを実施した日付にマークが付いたカレンダー。
    -   選択した日付のトレーニングログ一覧（同日分のみ）。
-   **リスト表示モード:**
    -   過去のトレーニング記録が日付の降順でリスト表示される。
    -   各リストアイテムには、日付、トレーニングの概要（種目数など）を表示。
    -   アイテムをタップすると詳細ビューに遷移する。
-   **分析表示モード:**
    -   記録済みログをもとにした集計グラフ（例：月別セッション数、カテゴリ別内訳）。
    -   集計対象期間やカテゴリを切り替える補助フィルタ（オプション）。
-   **詳細ビュー（リストアイテムタップ時）:**
    -   特定の日付のトレーニング詳細。
    -   種目、セット数、回数、重量。
    -   連携している場合は心拍数や消費カロリーなどのヘルスケアデータ。

## 3.3. 機能要件

-   **表示モードの切り替え:**
    -   ユーザーは表示モードを自由に切り替えることができる。
-   **カレンダー操作:**
    -   カレンダーの日付をタップすると、その日のトレーニング記録（存在する場合）のリストが下部に表示される。
    -   記録がなければ「データなし」メッセージを表示する。
-   **リスト操作:**
    -   リストを下にスクロールすると、過去のデータを順次読み込む（無限スクロール）。
    -   リストの各アイテムをタップすると、その記録の詳細ビューに遷移する。
    -   検索バーで種目名やメモを入力すると、該当アイテムのみ表示される。
    -   カテゴリフィルタで `strength` / `cardio` / `mobility` などを絞り込み、検索と組み合わせ可能。
-   **グラフ操作:**
    -   集計種別（例: 月別セッション数、カテゴリ別内訳）を切り替えるとグラフが更新される。
    -   データが存在しない場合は案内メッセージを表示し、グラフは非表示。
-   **データ編集・削除:**
    -   詳細ビューから、記録の編集（「2. 記録画面」に遷移）や削除ができる機能を持つ。

## 3.4. データ要件

-   `TrainingLog` (Domain/Models): SwiftDataからクエリで取得したすべてのトレーニング記録。
-   `HealthKit`データ: `Infrastructure/HealthKit`経経由で取得した、トレーニングに関連する心拍数や消費カロリーデータ。
-   `ExerciseCategory`/`BodyPart`: 種目ごとのカテゴリ・部位情報。リスト表示のサマリーとフィルタに利用する。
