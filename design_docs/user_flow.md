# ユーザーフロー

## 1. 初回利用時（オンボーディングと初期設定）

アプリの価値を伝え、ユーザーが継続利用するために必要な情報を設定するフロー。

1.  **アプリ起動 → ようこそ画面**
    -   アプリの主な機能とメリット（AIによるパーソナルプラン、簡単な記録、成長の可視化）を数画面で紹介する。
2.  **目標設定**
    -   ユーザーの主な目的を「筋力アップ」「減量」「健康維持」などの選択肢から選んでもらう。
    -   より具体的な目標（例: ベンチプレス100kg、体重-5kg）を入力するオプションも提供する。
3.  **基礎情報入力**
    -   身長、体重、年齢、性別、トレーニング経験（初心者、中級者、上級者）などを入力してもらう。これらの情報はプラン生成の精度を高めるために利用される。
4.  **ヘルスケアデータ連携許可**
    -   HealthKitへのアクセス許可をシステムダイアログで要求する。
    -   連携するメリット（心拍数や消費カロリーの自動記録など）を事前に説明する。
5.  **プランニング生成**
    -   入力された情報に基づき、AIが最初の長期・中期・短期プランをバックグラウンドで生成する。
    -   生成中はローディング画面やアニメーションを表示する。
6.  **メイン画面へ遷移**
    -   初期設定が完了し、生成されたプランが反映されたホーム画面が表示される。

## 2. 日々の利用時（トレーニング記録とAIアシスタント）

最も頻繁に利用される中心的なフロー。

1.  **メイン画面での確認とアクション**
    -   **今日のプラン確認:** ホーム画面に表示された今日のトレーニング概要を確認する。
    -   **AIアシスタントへの質問:** 必要に応じて、AI入力窓から体調や時間に関する相談を行う。
    -   **トレーニング記録開始:** 「記録を開始する」ボタンをタップして記録画面へ進む。
2.  **記録画面での入力**
    -   **種目選択:** その日行うトレーニング種目を選択・追加する。
    -   **データ入力:** セットごとに重量、回数などを入力する。セット間の休憩はタイマー機能を利用する。
    -   **記録完了:** トレーニングが終了したら「記録を保存」をタップする。データはSwiftDataに保存され、ホーム画面に戻る。
3.  **履歴画面での振り返り**
    -   ナビゲーションバーから「履歴」タブを選択し、履歴画面に遷移する。
    -   **カレンダー/リスト確認:** 過去のトレーニング実施日や内容を一覧で振り返る。
    -   **検索・カテゴリフィルタ:** 種目名やメモで検索し、`ExerciseCategory` で絞り込んで目的のログを見つける。
    -   **成長の確認:** 特定の種目のグラフを表示し、重量などの伸び率を確認してモチベーションを高める。

## 3. プラン管理時

目標の変更や進捗に合わせてプランを見直すフロー。

1.  **プランニング画面への遷移**
    -   ナビゲーションバーから「プラン」タブを選択し、プランニング画面に遷移する。
2.  **プランの確認**
    -   長期・中長期・短期の各プランの現在の目標と期間を確認する。
    -   詳細をタップして、週ごとや日ごとのトレーニング計画を見る。
3.  **プランの見直し**
    -   **AIによる再提案:** 「プランを再提案」ボタンをタップし、最新の進捗や新しい要望を伝えてプランを更新する。
    -   **採用フロー:** 提案リストから気に入ったプランを選択してアクティブプランを更新する。以前のプラン履歴は保持し、最新の採用日時で判定する。
    -   **手動での目標変更:** 目標の数値（重量、期間など）を直接編集する。

## 4. Apple Watch連携

Apple Watchを活用して、よりシームレスにトレーニングを記録するフロー。

1.  **Apple Watchアプリでの操作**
    -   Apple Watchでトレーニングアプリを起動する。
    -   今日のプランが表示され、「ワークアウト開始」をタップする。
2.  **トレーニング中の記録**
    -   Watchが自動的にワークアウト（心拍数、消費カロリーなど）を記録する。
    -   セット完了ごとに、回数や重量をWatchの画面でタップして記録する。
    -   休憩タイマーもWatch上で操作できる。
3.  **自動同期**
    -   ワークアウトを終了すると、記録されたすべてのデータが自動的にiPhoneアプリに同期される。
    -   ユーザーはiPhone側で追加の操作を行う必要はない。
