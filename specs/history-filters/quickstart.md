# 履歴フィルタリング クイックスタート

1. アプリを起動し、「履歴」タブへ移動する（SwiftData に `TrainingLog` が存在する前提）。
2. **リストモード**
   - 画面上部の検索バーから種目名やメモを入力して絞り込む。
   - カテゴリメニューで `ExerciseCategory` を選択すると該当カテゴリを含むログのみが表示される。
   - アイテムをタップすると詳細ビューに遷移し、種目とセット内容を確認できる。
3. **カレンダーモード**
   - カレンダーで日付をタップすると、その日のログだけがリスト表示される。
   - 別の日付を選ぶとリストが即座に切り替わる。
4. **分析モード**
   - 記録済みログに基づく月別・カテゴリ別の集計チャートを確認する。
   - データがない場合は案内メッセージが表示される。
5. ユニットテストは `swift test` で実行し、検索/カテゴリ/日付フィルタのロジックを含めて成功することを確認する。
