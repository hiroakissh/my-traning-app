# プランアクティブ状態管理 Quickstart

1. プラン生成
   - プランニング画面で「再生成」をタップするとAIへプロンプトを送信し、`PlanSuggestion`が3セクションに分割されて表示される。
2. プラン採用
   - 提案カードの「このプランを採用」をタップすると`ActivePlan`がSwiftDataへ保存され、カード上部にアクティブプランとして反映される。
3. 別プランへの変更
   - 追加の提案カードから同様に採用するとアクティブプランが更新され、履歴は`adoptedAt`で保持される。
4. ホームでの確認
   - ホーム画面にアクティブプラン概要が表示される。未採用の場合は案内メッセージが表示される。
5. テスト実行
   - `swift test`でマッピング・永続化テストを含むスイートを実行する。
