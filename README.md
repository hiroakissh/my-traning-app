# 🏋️‍♂️ トレーニング記録アプリ

## 概要

このアプリは、ユーザーの目標に合わせたトレーニングプランをAIが提案し、日々のトレーニングを記録・サポートする自分専用のトレーニング記録アプリです。ヘルスケアデータやApple Watchとの連携により、ユーザーの状況に応じた最適なプランニングと、継続的なモチベーション維持を支援します。

## 主な機能

### トレーニング記録と履歴管理

*   種目、重量、回数、セット数などの詳細なトレーニング記録。
*   過去のトレーニング履歴の閲覧と分析。

### AIアシスタントによるプラン提案

*   Foundation Modelを活用し、ユーザーの目標に応じた長期・中長期・短期のトレーニングプランを自動生成。
*   日々の体調やスケジュールに合わせて、今日のトレーニング内容や食事に関する具体的なアドバイスを提供。
    *   例：「今日は忙しいので、長期プラン達成のために何ができるか？」
    *   例：「今日は余裕があるので、追い込みたいです。何ができるか？」

### ヘルスケア連携

*   Apple Watchとの連携によるトレーニングデータの自動取得（心拍数、消費カロリーなど）。
*   ヘルスケアデータを取り込むことで、より精度の高いプランニングを実現。

### Apple Watch連携

*   Apple Watch上でのトレーニングデータ入力。
*   ランニングやその他の運動計測機能。

### Widget機能

*   ホーム画面のウィジェットで、目標までの進捗やトレーニング継続状況を可視化。
*   ユーザーのモチベーションを継続的に高めるための情報を表示。

### 拡張機能（今後の展望）

*   栄養データの記録と管理。
*   食事内容の記録と分析。

## 使用技術とアーキテクチャ

*   **開発言語:** Swift
*   **UIフレームワーク:** SwiftUI
*   **データ永続化:** SwiftData
*   **AI機能:** Foundation Model
*   **デバイス連携:** HealthKit, CoreMotion
*   **アーキテクチャ:**
    *   個人開発の保守性を考慮した、シンプルなViewModelレスアーキテクチャを採用。
    *   クリーンアーキテクチャに厳密には従わず、シンプルで理解しやすいコードベースを目指す。
